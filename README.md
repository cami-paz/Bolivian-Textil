# Chaquetas Cami · Bolivian Textil 🦖

Experiencia de realidad aumentada para las etiquetas de las chaquetas: escaneas el código y aparece un T-rex 3D que puedes poner en tu casa.

**Link:** https://cami-paz.github.io/Bolivian-Textil/

- `index.html` – página (Google model-viewer, sin apps: Android con Chrome, iPhone con Safari)
- `trex-v3.glb` – modelo 3D animado (mordida en loop), optimizado para celular
- `etiqueta/` – QR de pago (Banco Fie), QR que abre el T-rex y la etiqueta doble para colgar en la chaqueta

Modelo 3D: "Animated T-Rex Dinosaur Biting Attack Loop" por LasquetiSpice (Sketchfab), licencia CC BY 4.0.
